# 📊 IBM EDA Project – Startup Data Analysis

## 1.📝 About the Project

   This project is based on Exploratory Data Analysis (EDA) using IBM tools. The main purpose of this project is to understand the startup dataset by analyzing it in a simple and clear way.
   In this project, I have worked on cleaning the data and creating different visualizations to better understand how startups grow, how much funding they receive, and what factors may affect their success or          failure.

## 2. Dataset Information

   This dataset contains information about startups such as industry, funding stage, revenue, valuation, number of employees, etc.

## 3. Steps Performed in Project

  In this project, I performed the following steps:
  
 - Loaded the dataset
 - Data cleaning
 - Removed missing values
 - Removed duplicate entries
 - Created new column (Startup Age)
 - Converted data types
 - Basic data analysis

## 4. Data Visualization

  To make the data easy to understand, I have created the following Graphs:

 - Startup Age Distribution
 - Success Rate by Industry
 - Funding vs Valuation
 - Revenue Distribution
 - Correlation Heatmap

## 5. Tools & Libraries Used

   To make this data project, I have used the following Libraries:

 - Python
 - Pandas
 - NumPy
 - Matplotlib
 - Seaborn
 - Plotly

## 6. Conclusion

   This project helped in understanding how data can be analyzed using EDA techniques to find useful insights.
